# FactShield AI — User Guide

## Getting Started

1. **Register** — Create a free account at `/register`
2. **Login** — Sign in at `/login`
3. **First user** automatically becomes Admin

---

## Features

### Analyze News

Navigate to **Analyze** from the navbar.

**Paste Text:**
1. Select "Paste Text" tab
2. Paste your news article
3. Click "Analyze Now"
4. View prediction (Fake/Real), confidence score, explanation, and top keywords

**Analyze URL:**
1. Select "Analyze URL" tab
2. Paste an article URL
3. Click "Analyze Now"
4. The system extracts and analyzes the article content

### Fact Verification

Navigate to **Verify Facts**.

1. Enter a claim (e.g., "Vaccines cause autism")
2. Click "Verify Claim"
3. View status: Verified, Unverified, or Inconclusive
4. Read the verification result and sources

### News Summarizer

Navigate to **Summarize**.

1. Paste a long article
2. Click "Generate Summary"
3. Copy the summary with one click

### Dashboard

View your analytics:
- Total analyses performed
- Fake vs Real news counts
- Verification requests
- Pie chart and weekly bar chart

### Prediction History

Navigate to **History**.

- View all past analyses
- Click eye icon for details
- Delete old predictions

### Profile

Update your name, username, and email.

### Admin Dashboard

Available to admin users only.

- View all registered users
- System-wide statistics
- Activity logs

## Understanding Predictions

| Element | Meaning |
|---------|---------|
| **Prediction** | FAKE or REAL classification |
| **Confidence** | Model certainty (0-100%) |
| **Keywords** | Words that influenced the prediction |
| **Explanation** | Human-readable reason for the classification |

### Confidence Levels

| Range | Interpretation |
|-------|---------------|
| 90%+ | Very confident |
| 70-89% | Moderately confident |
| Below 70% | Low confidence — verify manually |

---

## Tips

- Longer articles produce more accurate predictions
- Always cross-reference with reputable fact-checking sites
- Use Fact Verification for specific claims
- Check Prediction History to track trends
